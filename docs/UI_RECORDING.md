# RescueLink 界面升级与录制说明

本次基于同伴仓库提交 `945b1cc29f999f94745178cce8233a66139ef64e` 修改。保留通信协议和教师原版 Cable，重点增加可录制的分级展示与真实结果呈现。原有传输模式为 Stop-and-Wait / GBN，本次没有将其替换为 SR；没有新增无线或 MIMO。

## 启动

在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

已有 `.venv` 时也可使用 `.venv\Scripts\python.exe -m streamlit run app.py`。Windows 可双击根目录的 `start_ui.bat`，它优先使用现有 `.venv`。浏览器通常打开 http://localhost:8501 。本应用本地运行，不依赖公网服务。

## 四个展示页面

|页面|用途|实际行为|
|---|---|---|
|指挥总览|Level 3 现场展示|实时星形网络、接收图片、分片确认进度、SOS回执、事件和指标|
|Level 1 · 点对点|基础链路录屏|独立 A→B Cable，逐片发送，真实调制/译码/CRC/重组，不经过交换机、不使用 ARQ|
|Level 2 · 星形转发|转发录屏|载入 A→D 文本和 C→B 状态请求，展示地址表、两跳信道和响应|
|实验与对照|汇报结果|读取仓库已保存的离线结果，明确生成时间和样本规模，不伪装为本轮实时实验|

## Level 1 录屏

1. 打开侧栏，设置非零噪声，例如 0.15；可选择 BPSK/ASK/BFSK。
2. 进入点对点页，保留默认中文长消息，选择每片 128 B。
3. 点击“开始点对点传输”，每次刷新发送一个分片。
4. 需要逐片解释时先暂停，再点击“单步发送一个分片”。
5. 展示分片状态、真实载荷波形、CRC/FEC统计和最后出现的恢复文本。
6. “逐片检错记录与实验导出”可下载当次 JSON。

绿色分片表示本片通过 PHY/FEC/CRC；红色表示拒绝。出现缺片时，不显示发送端原文作为接收成功。Balanced/Survival 的载荷有汉明码，Fast 没有；独立 PHY 头始终保护。点对点成功后自动关闭其物理工作线程。

## Level 2 录屏

1. 进入“Level 2 · 星形转发”，点击“载入 Level 2 场景”。
2. 场景先暂停，便于解释头部和端口。
3. 点击“暂停 / 继续”或“单步推进 12 个事件”。
4. 展开链路详情，展示地址→出口表和 up/down 各方向 Cable 调用。
5. 接收区出现 A→D 文本及 B→C 状态响应；最近发送帧显示实际 src/dst、序号与检错结果。

拓扑连线与数据点由实际在途帧的 start/end 和当前模拟时间决定；不是固定循环动画。网络完成后连接回到空闲，不把已经结束的帧继续显示为在途。

## Level 3 现场演示

建议保留 Auto / BPSK / Priority / GBN、窗口 8、下行倍率 2、种子 42。

1. 点击“应用配置 / 重置”，再点击“运行完整 Demo”。
2. 展开“演示控制”，点击“推进至预览到达”。网络继续执行真实事件，到接收端实际获得预览时自动暂停。
3. 解释预览来自网络字节、原图仍在传输；接收端未提前加载原始图片。
4. 点击“推进至 SOS 送达”，观察真实入队与接收时刻，以及 SOS 回执。
5. 再点击“推进至原图校验”，查看完整原图、SHA-256和实际接收文件下载。
6. 可手动“加入干扰 σ=0.85”或“恢复链路 σ=0.12”，修改的是当前原版 Cable 的噪声参数，不重置已经传输的数据。

完整 Demo 自带模拟 22s SOS、32s 加噪、55s 恢复。手动注入干扰时要知道脚本后续仍会按时修改信道。若要完全手动控制，重置后用“开始图片上传”提交任务，按需要触发 SOS 和噪声。

“推进至…”只设置暂停条件，不跳过信道、不直接设置完成状态。如果里程碑已经达到会立即暂停；任务失败或队列结束却未达到时会明确提示。预览到达、原图应用完成、发送端收到所有确认可能是不同的时间点。

## 画面与录屏建议

- 推荐 1920×1080、浏览器 100% 或 90% 缩放；总览以拓扑、接收图像、关键事件和指标为重点。
- 侧栏可以收起。开启“录制模式”后总览隐藏长日志；Level 2 仍保留转发详情。侧栏入口继续可用。
- 操作后等待页面刷新完成再点击下一项，特别是跨页面和重置之后。
- 网络“播放速度”表示每刷新推进的事件数。它不改变模拟时间、网络吞吐率或 SOS 时延。
- Level 1、2 录屏可分别保留 25–40 秒；Level 3 按课程要求现场操作。离线图表不能代替现场功能。
- 使用系统录屏或 OBS 录制浏览器窗口即可。所有统计可同步下载 JSON/JSONL。

## 与旧界面的主要区别

- 暖白背景、低饱和绿与赭红色强调，布局按总览/细节划分。
- 独立 Level 1 录屏页和 Level 2 预置场景。
- 接收端图片、实际确认进度、SOS消息与回执直接可见。
- 真实里程碑自动暂停，便于在接收结果处讲解。
- 支持运行中改变噪声；侧栏仍负责下一次重置的配置。
- 波形可选择数据载荷或前导。旧版只取波形最前面的 512 个采样，基本属于固定保护前导；本版额外保留真正载荷位置的采样。
- 原始事件、配置与指标可以导出；离线实验明确标记为已保存数据。
