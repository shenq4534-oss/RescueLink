## 现场点击顺序

提前执行 quick 实验，启动 `streamlit run app.py`。打开页面，保持 Auto/BPSK/Priority/GBN，窗口8，下行倍率2；点击“应用配置 / 重置”。

简洁路径：“运行完整 Demo”→“链路与事件”看 mode_changed 和调度→“接收端”看真实预览与校验后原图→“已计算实验”看 SOS 对照。完整 Demo 自动生成 SOS 和信道升降，避免台上手动改输入。

手动路径：“开始图片上传”→“单步推进”或继续→预览出现后暂停→“触发 SOS”→继续→查看 SOS_ALERT 与 SOS_ACK→原图 SHA。噪声侧栏配置在新场景生效；需要现场自动噪声变化用完整 Demo。图片优先级/低噪声情况下均可单步复查顺序。

底层验真路径：顶部“底层实验室”→输入 `SOS：请救援`→选16字节分片→“运行逐层实验”→依次点四个步骤→下载JSON。再切回应急网络，重置后只发一条短文本，在“逐帧追踪”对照同一 message_id/sequence 的上行、下行哈希和ACK返回。讲清楚：同一电脑上的软件节点仍然需要经过老师的波形模型；换成两台电脑抓到TCP包，不能单独证明调用了Cable。
